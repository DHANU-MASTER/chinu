# 14. MISCONCEPTION DETECTION

This is one of the main differentiators.

When the student answers incorrectly:

DO NOT simply display:

```text
Wrong answer.
```

Instead:

1. Evaluate the answer.
2. Identify the likely misconception.
3. Explain why the student's reasoning may have seemed reasonable.
4. Change the teaching strategy.
5. Change the visual analogy.
6. Ask a simpler verification question.
7. Continue only after improvement.

Example:

Student:

```text
Acceleration doubles.
```

Teacher:

```text
I can see why you thought that.
Let's look at the relationship between force, mass and acceleration.
```

Then show:

```text
a = F / m
```

with an animated visual.

Then ask a simpler question.

```text

```

IMPORTANT:

Browser MediaRecorder commonly produces WebM rather than MP4.

Therefore:

* Prefer `video/webm`
* Detect supported MIME types
* Never falsely label a WebM file as MP4
* Download the actual playable format
* Display the correct extension

If MP4 recording is genuinely supported by the browser, use it.

Otherwise provide a working `.webm` download.

**A working download is more important than pretending the output is MP4.**
